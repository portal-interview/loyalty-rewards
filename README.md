# loyalty-rewards

Customer loyalty and rewards service for Flavortown — tracks points, perks, and repeat-visit rewards, with loyalty activity recorded on a blockchain for a shared, tamper-evident history.

Part of the **ordering-system**, owned by **team-triple-d**. Provides the `loyalty-rewards-api`, consumes the `menu-api` to know what regulars are ordering, and anchors points activity to the loyalty blockchain.

> **Demo:** The blockchain integration is a demonstration of the architecture. Loyalty points are promotional rewards, not cryptocurrency, and have no cash value.
